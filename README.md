# FPGA-Bioacoustics-Monitor
A bioacoustics monitor that can classify different bird species by their vocalizations.  By processing acoustic frequencies and audio pitch in hardware, the system will accurately identify four species of birds.
The system takes analog audio through a microphone, converts it to digital audio, and passes it to an audio analyzer to identify the bird species using signal frequency and pitch. After guessing, it outputs an image of the bird to the monitor through a VGA adapter. A user-friendly interface will display on the monitor which birds the system can classify.
